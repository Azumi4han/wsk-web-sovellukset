# Week 4-5 - React

React exercises for the Web Applications course.

Open [this app](https://users.metropolia.fi/~igorkarp/upload/) to view it in the browser.

## Branches

- `main` - Vite + React starting point
- `first-component` - first components and a media table
- `state-management` - selected media item with a dialog (`SingleView`)
- `routing` - React Router views and a single media view
- `hooks` - data fetching with `useEffect`, Media API and Auth API
- `custom-hooks` - API calls moved to `useMedia` in `hooks/apiHooks.js`
- `forms` - login and register forms
- `context` - user context, protected routes
- `upload` - file upload
