# Week 4 - React

React exercises for the Web Applications course.

Open [this app](https://users.metropolia.fi/~igorkarp/hooks/) to view it in the browser.

## Branches

- `main` - Vite + React starting point
- `first-component` - first components and a media table
- `state-management` - selected media item with a dialog (`SingleView`)
- `routing` - React Router views and a single media view (`wsk-routing` build)
- `hooks` - data fetching with `useEffect`, Media API and Auth API

## Environment

The `hooks` branch reads the API addresses from `.env.local` (see `.env.example`).
The Media API and the Auth API are only available inside the Metropolia network
or through the Metropolia VPN.
